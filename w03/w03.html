Where we left off

Week 1 covered descriptive statistics (mean, variance, standard deviation) on real polling data. Week 2 introduced probability distributions and, with the Central Limit Theorem, the key fact that a sample mean’s own variability — its standard error — shrinks as the sample size grows. Both weeks stopped at a single number: one mean, one proportion, one point. This week asks the natural next question: how much do we trust that single number, and how do we express that trust as a range of plausible values instead of a false sense of precision?

Statistical inference: vocabulary

  • An estimand is the actual quantity we want to learn about — defined by the research question itself, before any data or model comes in. Here: the AfD’s true level of support at a given moment.
  • A parameter is that same estimand once expressed as a fixed, unknown feature of a population or probability model — e.g. the true share of the electorate that supports a party at a given moment, which no poll ever observes directly.
  • An estimator is a function applied to a sample that produces a guess at that parameter — mean() is the estimator for a population mean.
  • An estimate is the actual number an estimator returns for one particular sample.

Because we only ever observe one sample, our estimate carries uncertainty. A confidence interval (CI) turns that single estimate into a range: an interval that will contain the true parameter in some fixed proportion of repeated samples.

Point estimate and standard error

Week 2’s Central Limit Theorem gave us the sampling distribution of a mean, — its standard deviation, the standard error, is estimated from a single sample as:

afd_stats <- afd_polls |>
  summarize(
    mean_share = mean(share),
    sd_share   = sd(share),
    n          = n()
  )
afd_stats
# A tibble: 1 x 3
  mean_share sd_share     n
       <dbl>    <dbl> <int>
1       20.7    0.737    25

Pull the three pieces we need out of that summary:

mean_share <- afd_stats |> pull(mean_share)
sd_share   <- afd_stats |> pull(sd_share)
n_polls    <- afd_stats |> pull(n)

se_share <- sd_share / sqrt(n_polls)
se_share
[1] 0.1474223

Confidence intervals for a mean

  1. Analytically — quantiles of the Normal approximation.
  2. By simulation — draw from the assumed sampling distribution directly.
  3. By bootstrap — resample the polls themselves, with replacement.

We compare all three once we have them.

1. Analytical

with the 2.5%/97.5% quantiles of the standard Normal.

ci_analytical <- mean_share + qnorm(c(0.025, 0.975)) * se_share
ci_analytical
[1] 20.43106 21.00894

2. Interpreting a confidence interval

A 95% CI does not mean “95% probability the true mean is in this particular interval” — the true mean either is or isn’t in it, no probability about it. It means: if we repeated the whole sample-and-build-a-CI process many times, about 95% of the resulting intervals would contain the true parameter. We can only show this by pretending to know the truth — so, purely for this demonstration, we invent a population with a known true mean, using our own data’s poll-to-poll variability as the population’s spread:

true_mean <- 21
demo_pop  <- rnorm(10000, true_mean, sd_share)

expand_grid() lays out every (trial, draw) combination at once — group_by(trial) + summarize() then computes each trial’s own sample mean and CI in one vectorized pass, no loop needed. Each trial resamples as many polls as our real window actually had:

n_trials <- 100

ci_trials <- expand_grid(
  trial = 1:n_trials,
  draw  = 1:n_polls
) |>
  group_by(trial) |>
  mutate(value = sample(demo_pop, n(), replace = TRUE)) |>
  summarize(
    est     = mean(value),
    se      = sd(value) / sqrt(n()),
    lo      = est + qnorm(0.025) * se,
    hi      = est + qnorm(0.975) * se,
    .groups = "drop"
  ) |>
  mutate(missed = lo > true_mean | hi < true_mean)

ci_trials |> count(missed)
# A tibble: 2 x 2
  missed     n
  <lgl>  <int>
1 FALSE     99
2 TRUE       1
ci_trials |>
  ggplot(aes(x = est, y = trial, xmin = lo, xmax = hi, color = missed)) +
  geom_pointrange(linewidth = 0.3, size = 0.3) +
  geom_vline(xintercept = true_mean, color = course_primary, linewidth = 0.8) +
  scale_color_manual(values = c("FALSE" = "grey40", "TRUE" = "firebrick")) +
  labs(
    title = "100 samples, 100 CIs: most contain the true mean",
    x     = "Estimate",
    y     = "Trial",
    color = "Missed truth?"
  ) +
  theme_intror()

4. Bootstrap

Resample the polls themselves, with replacement, many times — same vectorized “one big tibble, group_by(trial)” pattern as the coverage demo above, just resampling real observed shares instead of a known population. sample() draws from a plain vector, so afd_shares is pulled out once first:

afd_shares <- afd_polls |> pull(share)
n_boot <- 1000

boot_means <- expand_grid(
  trial = 1:n_boot,
  row   = 1:n_polls
) |>
  group_by(trial) |>
  summarize(boot_mean = mean(sample(afd_shares, n(), replace = TRUE)), .groups = "drop")

boot_mean_values <- boot_means |> pull(boot_mean)
ci_bootstrap <- quantile(boot_mean_values, c(0.025, 0.975))
ci_bootstrap
 2.5% 97.5%

Confidence interval for a ratio of proportions

Not every quantity of interest has a clean standard-error formula. A ratio of two proportions is a case where the analytical derivation gets awkward fast, but simulation still works exactly the same way. This example is from the lecture: in a sample of 500 men and 500 women, 55% of men and 65% of women report voting for a left-wing party. We want a CI for the ratio of these two proportions, .

p_hat_men   <- 0.55
p_hat_women <- 0.65
n_men       <- 500
n_women     <- 500

se_men   <- sqrt(p_hat_men * (1 - p_hat_men) / n_men)
se_women <- sqrt(p_hat_women * (1 - p_hat_women) / n_women)
ratio_sim <- tibble(
  p_men   = rnorm(nsim, p_hat_men, se_men),
  p_women = rnorm(nsim, p_hat_women, se_women)
) |>
  mutate(ratio = p_men / p_women)

ratio_values <- ratio_sim |> pull(ratio)
ci_ratio <- quantile(ratio_values, c(0.025, 0.975))
ci_ratio
     2.5%     97.5% 
0.7646757 0.9391692

Confidence intervals for a difference in means

  1. Analytically — Normal approximation, combining both groups’ own variance.
  2. By simulation — draw each group’s sampling distribution, subtract.
  3. By bootstrap — resample each group with replacement, subtract.
  4. t.test() — R’s built-in shortcut for the analytical version, previewing the formal hypothesis test Week 6 covers in full.

1. Analytical

se_diff <- sqrt(var_east / n_east + var_west / n_west)
ci_diff_analytical <- diff_observed + qnorm(c(0.025, 0.975)) * se_diff

All four intervals land in the same place, comfortably clear of zero. They differ only in their assumptions: analytical and simulation both rely on the Normal approximation, t.test() uses the same SE but a slightly larger multiplier for having to estimate the variances, and only the bootstrap drops the Normal assumption for the data’s own shape — yet all four assume independent draws from one stable distribution.

Concluding remarks

You’ve now built confidence intervals three different ways — analytically, by simulation, and by bootstrap — for both a single mean and a difference in means, and seen R’s own shortcut (t.test()) reproduce the analytical result. There’s always a trade-off between how confident we want to be and how precise the resulting statement is: a wider interval is more likely to capture the truth, but says less. The real fix for that tension is a bigger sample, not a wider interval. Week 6 picks this thread back up and turns “does zero sit outside this interval?” into a formal hypothesis test, with its own machinery for deciding how surprised to be.
